Fluid & Particle Simulation

High-performance physics solver for fluid dynamics, built from scratch to study core simulation mechanics.

Developed a custom particle engine designed for scalability and deep understanding of physics programming. Made as a school project, I went beyond and built a fluid simulation and optimised it. The system adapts its execution based on particle count requirements.

  • Inside Unreal but using native C++.
  • Implemented spatial simulation algorithms for fluid behaviors.
  • Dynamic scaling utilizing GPU optimizations including Compute Shaders and GPU Instancing/Batching for massive particle counts.
  • Focused on memory alignment and data-locality to ensure high-performance rendering.
Research / Algorithms

Procedural Flower Evolution

Research thesis: Procedural generation and adaptation of flower using interactive genetic algorithms.

An exploratory system evaluating how procedural 3D plant models can mutate and adapt. While the thesis focuses on small-scale individual flora, the ultimate architectural goal is full biome generation.

  • Implemented an Interactive Evolutionary Computation approach where the user acts as the fitness function to guide plant mutation.
  • Explored Crossover and Procedural Mutation algorithms to create organic variations.
  • Studied state-of-the-art scientific papers on algorithmic plant growth.
C# / Unity

Storygami

Puzzle game featuring a state-recording system and "time-manipulation" of clones.

A puzzle game presented in an isometric view, featuring the unique aspect that allows players to create clones to solve each room. However, the player requires time to generate these clones, and their time is limited.

Architected a system for a 3rd-year student project, focusing heavily on performance constraints and data management.

  • Developed a Time Record/Playback system saving velocities and player actions.
  • Heavily optimized the recording loop to fluidly support up to 100 simultaneous player clones without frame drops.
